03Research

Publication

IEEE · National Conference on Communications (NCC) 2023 · First author

Limitations of the Perceptual Deadband Approach for Haptic Data Compression

Haptic teleoperation systems save bandwidth by sending only samples that differ perceptibly from the last perceived force. We ran a psychophysical experiment with staircase force stimuli and trained a classifier on user responses. It showed that perception depends on both the current and previous stimuli, which the standard deadband model ignores.
